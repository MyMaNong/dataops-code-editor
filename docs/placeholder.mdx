# 概述

占位符（Placeholder）功能为 CodeEditor 提供了在编辑器为空时显示提示文本的能力，类似于 HTML 中 input 元素的 placeholder 属性。

## 引入方法

```js
import { PlaceholderContentWidget } from 'dataops-code-editor';
```

## 功能说明

* 当编辑器内容为空时，会显示指定的占位符文本
* 用户开始输入内容后，占位符文本会自动隐藏
* 占位符文本通常用于提示用户编辑器的用途或输入格式要求

* 需要先初始化 CodeEditor 基础功能
