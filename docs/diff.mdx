# 概述

代码比对（Diff）功能是 CodeEditor 的一个重要特性，用于比较两个代码版本之间的差异。该功能可以清晰地显示代码的添加、删除和修改部分，帮助开发者快速识别代码变更内容。通过可视化的方式展示差异，提高代码审查和版本管理的效率

## 引入方法

```js
import { setupDiffCodeEditor } from '@dataops/code-editor';
```

## 功能说明

* 可视化显示两个代码版本之间的差异
* 使用不同颜色标识新增、删除和修改的代码行
* 支持并排（side-by-side）和内联（inline）两种显示模式
* 提供导航功能，可在差异点之间快速跳转
* 支持语法高亮，提高可读性
* 支持大文件的高效比对

## 注意事项

* 比对功能需要提供原始代码和修改后代码两个版本
* 大文件比对时注意性能影响，可考虑分块加载
* 可根据需要选择并排或内联显示模式
* 支持多种编程语言的语法高亮
* 注意在组件销毁时清理相关资源
* 比对结果会自动更新，当代码内容发生变化时
