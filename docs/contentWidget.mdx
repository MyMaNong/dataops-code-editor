# 概述

内容部件（Content Widget）是 CodeEditor 的一个重要功能模块，用于在编辑器中添加自定义的交互式组件。通过内容部件，开发者可以在编辑器的特定位置插入自定义 UI 元素，实现增强的编辑体验。

## 引入方法

```js
import { setupContentWidgetFeature } from '@dataops/code-editor';
```

## 功能说明

* 允许在编辑器中添加自定义 UI 组件
* 支持在指定位置定位和显示部件
* 可以与编辑器内容进行交互

## 使用示例

## 注意事项

* 需要先初始化 CodeEditor 基础功能
* 每个小部件必须有唯一的 ID，避免冲突
* 需要正确实现部件的 getPosition 方法以确定显示位置
* 注意部件的 DOM 节点管理，避免内存泄漏
* 可以根据需要自定义部件的样式和行为
* 在适当的时候调用 dispose 销毁部件
